# 微信小程序开发与验收

客户端与 H5 共用账号、业务 API 和数据。日常登录使用平台账号密码；学校 CAS/OIDC 仍只负责注册实名校验。本文说明源码构建，不代表微信审核、上传或真机验收已完成。

## 构建与导入

使用 Node.js 22，在 `source/` 执行：

```bash
pnpm install --frozen-lockfile
pnpm dev:mp-weixin
# 发布构建
pnpm build:mp-weixin
```

在不入库的 `.env.local`（开发）和 `.env.production.local`（发布）中设置 `VITE_API_BASE_URL`，值为实际部署的 HTTPS 网关根地址，可包含反向代理前缀；不要追加 `/api/v1`，业务请求会自动携带该路径。小程序无法使用 H5 的同源地址或开发代理。发布构建会拒绝空值、HTTP、本机和示例地址。

微信开发者工具导入 `source/dist/dev/mp-weixin/` 或 `source/dist/build/mp-weixin/`。AppID 沿用 `manifest.json` 中的项目配置。SWC 关闭和 `miniprogramRoot` 直接由 manifest 生成，开发监听第一次编译就生效，不需要等进程退出，也不需要手改产物。组件启用按需加载。

`build:mp-weixin` 编译完成后自动检查 AppID、域名校验开关、页面和组件依赖、tabBar 图标及每包 2 MiB 的保守体积上限。微信最终上传体积仍以开发者工具或官方 CI 为准。`dist/` 不提交。

## 服务端与微信配置

- **先更新本次服务端代码，再使用新小程序。** 微信把业务 PATCH 请求转换为 `POST + X-HTTP-Method-Override: PATCH`；Fastify 在路由匹配前恢复 PATCH，继续执行原路由的字段、版本、登录和权限检查。反向代理须透传该请求头。旧服务端没有此兼容入口，资料与群管理保存会失败。H5 仍直接发送 PATCH。[方法支持表](https://uniapp.dcloud.net.cn/api/request/request.html)
- 在微信公众平台为实际 API 配置 request 合法域名，为附件下载配置 downloadFile 合法域名；远程图片域名也须按微信规则配置。聊天分片使用 request 的 PUT，图片分片复用现有接口。不要通过关闭 `urlCheck` 掩盖正式域名问题。
- 选图、相机及聊天文件选择涉及微信隐私接口，需在公众平台按实际用途完成用户隐私保护指引与所需声明，并在真机验证同意、拒绝及取消流程。[微信隐私指引](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/)
- 学校注册实名的安全回跳绑定尚未实现小程序方案，继续显示不可用提示；已有账号可登录，符合条件的用户可走已有人工复核入口。不能把 web-view 能打开学校页面当成安全注册流程已完成。

## 已适配的行为

- 资料编辑及群管理保留 PATCH 业务语义。
- 聊天轮询、返校管理分页使用普通字符串编码，不依赖浏览器的 `URLSearchParams`。
- 选择微信原生照片时，可识别没有扩展名的临时文件路径。
- 聊天通过原生选图或聊天文件选择器读取文件，按服务端分片大小上传，不把整文件载入内存。暂停后重新选择原文件可继续；微信续传会重传已收分片，由服务端比较 SHA256，拒绝同名不同内容文件。弱网重试及会话切换保留隔离检查。
- 附件可打开 PDF、Office 文档或预览图片；其他文件类型提示在浏览器下载。服务端的 5 GB 上限不代表微信设备可选择、存储或传输同样大小的文件，实际受微信和设备限制。
- 聊天页不再重复扣除原生导航高度，详情弹层有明确滚动高度。同城互动地图外链使用配置网关，微信通过复制链接在浏览器打开。

## 验证记录与真机步骤

2026-09-21 在 Node.js 22 完成自动测试和微信/H5 构建。微信产物包含 51 个页面，主包约 1.53 MiB。开发监听模式已检查首次生成的工程配置。自动测试覆盖方法兼容及越权、微信无 DOM 环境的文件读写、上传暂停/续传、换号隔离、分页编码和构建门禁。

以下项目仍需在有权限的微信开发者工具及 iOS、Android 真机完成：

1. 开启合法域名校验，检查五个 tab、首屏图片、资讯正文和模块关闭状态。
2. 登录、冷启动恢复、修改资料、初始密码修改及退出后换号。
3. 发送文字、照片和 PDF；上传中暂停、断网恢复、选择错误原文件续传；下载中退出或换号。
4. 聊天键盘弹出、长会话滚动、底部安全区、详情弹层长内容滚动。
5. 返校管理人员中文搜索和多页数据；同城地图外链复制与打开。
6. 照片/相机/聊天文件的隐私授权同意、拒绝及取消；人工复核材料上传。

源码变更没有重新生成旧交付包的 `handoff-manifest.json`，也没有改动 `runtime/`。正式交付包需要另走发布流程。
